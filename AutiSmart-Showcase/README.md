# AutiSmart Showcase (Public Summary)

This folder is a public-safe showcase for the AutiSmart Final Year Project (FYP).

## Important Privacy Note

- The original implementation repository is private.
- Source code, architecture internals, API secrets, and deployment configuration are intentionally not included here.
- This showcase exists only to present project goals, scope, and high-level outcomes.

## Project Overview

AutiSmart is a care-support platform designed around autism-focused workflows. The project concept includes role-based use cases, child progress workflows, and structured activity guidance.

## Showcase Scope

This public folder includes:
- A high-level project README
- A static overview page for presentation

This public folder does not include:
- Real backend or frontend source files
- Internal business logic
- Database schema or private data
- Credentials or environment files

## Why This Structure

This approach allows portfolio visibility while preserving private intellectual work and sensitive implementation details.

## Current Status

- Private development repository: maintained separately
- Public showcase: active and safe for profile/recruiter viewing
