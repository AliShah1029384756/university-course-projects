🧠 Final Year Project • Full-Stack Platform

AutiSmart

A comprehensive care-support platform for autism workflows with role-based access and engagement tools.

Full-Stack (React + Node.js) Role-Based Access Control Real-Time Workflows Therapy-Oriented Design

🎯 Project Vision

AutiSmart is designed to bridge the gap in autism-focused care management. The platform supports caregivers, educators, and specialists through structured workflows, progress tracking, and interactive engagement tools. A real-world problem solver built with modern web technologies.

💻 Technology Stack

  • Frontend: React 19, Vite, React Router, Bootstrap
  • Backend: Node.js, Express.js
  • Database: MongoDB with Mongoose
  • Auth: JWT + OTP Email Verification
  • AI: Groq SDK for recommendations

🔑 Core Features

User Authentication Role-Based Access Child Management Assessment Tracking Activity Recommendations Progress Reports Real-Time Notifications Admin Dashboard

👥 User Roles

  • Caregiver: Manage children, track progress, engage with activities
  • Expert/Educator: Review assessments, provide recommendations
  • Admin: System management, user administration, assessment curation

📊 Data-Driven Design

The platform emphasizes structured data collection and visualization. Assessment results, activity engagement, and progress metrics inform personalized recommendations and intervention planning.
