Inventory Management System (IMS) - OOP Project

Group Roll Numbers:
- <ROLL_NO_1>
- <ROLL_NO_2>

Project Type:
- C++ (Visual Studio project)
- Runs as a console-based IMS application

Implemented Modules:
1. Administrator Module
- Sign in (admin/admin)
- Add/Edit/Delete Shopkeeper
- Add/Edit/Delete Customer
- Add/Edit/Delete Product
- View lists of Shopkeepers, Customers, Products

2. Shopkeeper Module
- Register
- Sign in
- Add Product
- Edit Own Product
- View Own Products

3. Customer Module
- Register
- Sign in
- Input wallet amount after login
- View products
- Purchase product (add to cart)
- View cart
- Update cart quantity
- Delete cart item
- Checkout with 2% tax and 200 delivery charges

Data Files Used (as required):
- shopkeeper.txt
- customer.txt
- products.txt
- addToCart.txt

Sequence to Run Program:
1. Open TestProjectGUI.sln in Visual Studio.
2. Select x64 Debug (or x64 Release).
3. Build solution.
4. Run project.
5. Use main menu to access Admin, Shopkeeper, Customer modules.

Default Admin Credentials:
- Username: admin
- Password: admin

Notes:
- Replace roll number placeholders before final submission.
- Usernames are kept unique across Shopkeeper and Customer records.
- Product quantity 0 is treated as out of stock.
