## Overview

R + Shiny project for probability/statistical analysis and interactive visualization using a Valorant leaderboard dataset.

## Included Code Files

- `main.R`
- `test.R`

## Tech Stack

- R
- Shiny
- shinythemes
- ggplot2

## Run

From the project directory:

```bash
Rscript main.R
```

Or open in RStudio and run the Shiny app.
