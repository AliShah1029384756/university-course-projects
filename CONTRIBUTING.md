# Contributing

Thank you for helping improve this academic archive.

## Scope

- Documentation quality improvements
- Broken link fixes
- Setup instruction clarity
- Non-destructive structure improvements

## Rules

- Preserve original coursework intent and authenticity.
- Keep project names and historical context accurate.
- Avoid changing project code logic unless the change is clearly documented.
- Use small, reviewable pull requests.

## Process

1. Open an issue describing your proposed change.
2. Submit a focused pull request.
3. Include a short before/after summary.
4. Verify links and markdown formatting before submitting.
