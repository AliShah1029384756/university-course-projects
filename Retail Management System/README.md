## Overview

Desktop retail management application built with C# WinForms and Oracle integration for category, seller, product, and sales management workflows.

## Included Source

- WinForms source files (`*.cs`, `*.Designer.cs`, `*.resx`)
- Solution and project files (`Project.sln`, `Project.csproj`)
- Config files (`App.config`, `packages.config`)
- Supporting UI assets (`index.html`, `script.js`, `styles.css`)

## Tech Stack

- C# (.NET Framework 4.7.2)
- Windows Forms
- Oracle Managed Data Access
- Entity Framework

## Run

1. Open `Project.sln` in Visual Studio.
2. Restore NuGet packages.
3. Configure Oracle database connection.
4. Build and run.
