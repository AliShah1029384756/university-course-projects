# Snake Game (Assembly)

![Course](https://img.shields.io/badge/Course-Low%20Level%20Programming-0ea5e9)
![Language](https://img.shields.io/badge/Language-x86%20Assembly-16a34a)

## Overview

Low-level Snake game project written in x86 assembly (`snake.asm`).

## Build

```bash
nasm -o snake.com -fbin snake.asm
```

## Run

Run the generated COM file in a DOS-compatible environment or emulator.
