# Chess Game (Multiplayer)

## Overview

A real-time multiplayer chess application using Socket.IO and Chess.js.

## Tech Stack

- Node.js
- Socket.IO
- Chess.js
- HTML/CSS/JavaScript frontend

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

Default server port is `3000` unless overridden by environment configuration.

## Main Files

- `server.js`
- `public/index.html`
- `public/js/script.js`
