# Compiler Project

## Overview

A multi-deliverable compiler construction project containing lexical analysis, syntax analysis, semantic analysis, AST generation, intermediate code generation, and optimization stages.

## Structure

- `Deliverable 1 Frontend`
- `Deliverable 2 Middle-End`
- `Deliverable 3 Backend`
- `Commands.txt` for stage-wise execution commands

## Typical Tooling

- Lex/Flex
- Yacc/Bison
- GCC
- Python (for optimization stage)

## Run Notes

Refer to `Commands.txt` for command sequence per deliverable.
